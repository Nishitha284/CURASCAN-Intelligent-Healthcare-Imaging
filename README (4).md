<h3 id="project1">Project 1: CURASCAN – Intelligent Healthcare Imaging </h3>
<p>
This project involved designing and developing an AI-powered medical imaging system for disease detection and analysis. It focused on processing chest X-rays, CT scans, and MRI images using deep learning techniques such as DenseNet-121 for classification, U-Net for segmentation, and Grad-CAM for visual explanations. The system was developed to identify abnormalities, highlight affected regions through heatmaps, and generate automated reports, helping healthcare professionals make faster and more accurate diagnostic decisions.
